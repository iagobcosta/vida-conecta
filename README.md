# vida-conecta

### Plano de Desenvolvimento

- Planejamento;
- CI/MVP;
- CD/Observabilidade;
- Plano de Testes e de escala.

### Contexto do negócio

- Plataforma que conecta pacientes a médicos por consulta em vídeo, com histórico clínico compartilhado entre profissionais.

### SLA desejado

- 99.9% de disponibilidade; videochamada não pode ter mais que 1% de taxa de queda de conexão.

### Stack proposta (tecnologias, frameworks, linguagens, etc)

- Java Spring Boot
- PostgresSQL
- MongoDB
- React
- Tailwind
- Vite
- WebRTC
- AWS
- GitHub
